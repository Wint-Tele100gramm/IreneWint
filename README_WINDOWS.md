# Ирина на Windows 10/11 (временный сервер вместо приставки)

Работает всё, кроме AirPlay, DLNA, Bluetooth-приёма и эхоподавления — они только для Linux.
Клиенты ESP32, распознавание, голос, Home Assistant, Яндекс Музыка, веб-интерфейс — как на приставке.

## Установка

1. **Python 3.12, 64-bit** — https://www.python.org/downloads/windows/ («Windows installer (64-bit)»).
   При установке отметьте **Add python.exe to PATH**.
2. **Код Ирины**: https://github.com/Wint-Tele100gramm/IreneWint → переключите ветку на `rk3528` →
   Code → Download ZIP, распакуйте, например, в `C:\Irene` (или `git clone -b rk3528 ...`).
3. Запустите **install_windows.bat** (двойной щелчок). Он поставит пакеты, скачает модели (~155 МБ) и спросит:
   - **ключ клиентов** — если помните ключ с приставки (`token` из `runva_rooms.json`), вставьте его:
     тогда в клиентах ESP32 нужно поменять только адрес сервера;
   - **микрофон ноутбука как комната** — например «Кабинет», или Enter, чтобы не слушать его.
4. Для Яндекс Музыки: скачайте mpv для Windows (https://mpv.io/installation/, сборка x86_64),
   положите `mpv.exe` в папку `mpv` внутри папки Ирины.

## Запуск

**run_windows.bat** — окно покажет IP-адреса ноутбука. При первом запуске Windows спросит про брандмауэр:
разрешите доступ в **частных сетях**. Домашняя сеть Wi-Fi должна быть «Частной»
(Параметры → Сеть и Интернет → Wi-Fi → ваша сеть → Частная).

Веб-интерфейс: http://localhost:8765/ на ноутбуке или `http://<IP ноутбука>:8765/` с телефона.
Вход в Яндекс Музыку и токен Home Assistant — там же, в «Настройках».

## Переключить клиенты ESP32 на ноутбук

На каждом клиенте: откройте `http://<IP клиента>/` → **Setup** → «Адрес сервера» = IP ноутбука,
«Ключ» — ключ из шага 3 (если он тот же, что был на приставке, поле можно оставить пустым) → Save.
Когда приставка вернётся — так же впишите обратно её адрес.

## Советы

- Отключите сон ноутбука от сети: Параметры → Система → Питание → «Переводить в спящий режим» → Никогда.
- Перезапуск из веб-интерфейса работает, пока открыто окно run_windows.bat.
