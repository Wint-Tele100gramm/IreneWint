# Руслана — дополнение Home Assistant

Офлайн голосовой помощник для умного дома. Слушает и отвечает через клиенты ESP32 в комнатах; распознавание
речи (Vosk) и голос (Silero) работают на машине с Home Assistant без интернета. Устройства Home Assistant,
Яндекс Музыка по комнатам, погода, таймеры, анекдоты, ответы нейросети.

Подробности — на вкладке «Документация».
