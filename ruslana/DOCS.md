# Руслана в Home Assistant OS

Дополнение запускает сервер Русланы прямо на машине с Home Assistant: клиенты ESP32 в комнатах подключаются к нему,
распознавание речи и голос работают здесь же. Устройства Home Assistant Руслана видит сразу — адрес и токен
вводить не нужно.

## Установка

1. **Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории**, добавьте
   `https://github.com/Wint-Tele100gramm/IreneWint#rk3528`.
2. Найдите «Руслана», нажмите «Установить». Дополнение собирается на вашей машине: это 10–30 минут
   (скачивается около 1 ГБ — Python-пакеты и PyTorch).
3. «Запустить». При первом запуске скачаются модель распознавания (~25–70 МБ) и голос (~60 МБ) — смотрите «Журнал».
4. В журнале будет **ключ клиентов ESP32** — его и IP-адрес Home Assistant (порт 8765) вводят в клиенте
   при настройке (точка доступа `Ruslana-XXXXXX`, см. `esp32_client/README.md` в репозитории).

## Веб-интерфейс

Пункт «Руслана» в боковой панели Home Assistant (или «Открыть веб-интерфейс»): комнаты, команды, сценарии,
настройки, журнал фраз, прошивка клиентов. Через панель Home Assistant пароль не спрашивается; напрямую
(`http://<IP Home Assistant>:8765/`) — пароль равен ключу клиентов.

## Параметры

| Параметр | Что делает |
|---|---|
| `asr_model` | `small` — малая модель распознавания (~100 МБ памяти), `full` — полная, точнее (~250 МБ). |
| `multiroom` | Сервер Snapcast (порты 1704 и 1705): музыка играет на клиентах ESP32 синхронно, по комнатам. Если эти порты уже заняты (Snapcast в Music Assistant), выключите. |
| `download_jokes` | Скачать анекдоты при первом запуске (в фоне, несколько минут). |

## Что хранится

Всё в папке дополнения (`/data`): настройки (`options/`), модели, кэш озвучки, анекдоты, загруженные прошивки
клиентов. Обновление дополнения их не трогает; модели и кэш в бэкап не попадают (скачаются заново).

## Чем отличается от установки на приставку

- Комнаты — только клиенты ESP32: у машины с Home Assistant обычно нет своего микрофона и динамика.
- Нет Bluetooth и DLNA (звук с телефона по комнатам) — они работают через PipeWire приставки.
- Нет ускорения процессора на время речи (`cpu_boost`): из контейнера частотой процессора не управлять.
- Памяти нужно около 1 ГБ: голос Silero (PyTorch) — 450–650 МБ, распознавание — 100–250 МБ.

## Обновление

Код Русланы скачивается из репозитория при сборке. Новая версия дополнения в магазине — «Обновить»;
чтобы взять свежий код без новой версии — «Пересобрать».
