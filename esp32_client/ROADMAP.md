# План прошивки клиента

Пункты 1–4 сделаны в прошивке 2.0 (сервер и веб-интерфейс их поддерживают). Дальше — пункт 5.

1. **Сборка под S3 N16R8.** Плата ESP32S3 Dev Module, Flash 16MB, PSRAM OPI, разметка 16M Flash (3MB APP).
   Пины 35–37 заняты PSRAM. Буферы звука — в PSRAM.
2. **Настройки с сервера.** Сервер присылает `{"type":"config", ...}`: усиление, порог, паузу, название комнаты.
   Клиент применяет их сразу, без перезагрузки, и сохраняет в Preferences. В веб-интерфейсе эти поля станут изменяемыми.
3. **Живой индикатор уровня.** Клиент 4 раза в секунду отправляет уровень микрофона и шума
   (`{"type":"meter","level":..,"noise":..}`). Сервер передаёт его на страницу (событие `meter` уже есть).
4. **Медленная автоматическая регулировка усиления, только по речи:**
   - усиление подстраивается после каждой фразы к цели ~3000: на треть разницы, не больше ±3 дБ за раз;
   - посреди фразы усиление не меняется;
   - потолок усиления держит фоновый шум заметно ниже порога детектора речи;
   - при уровне выше 15000 усиление сразу снижается;
   - подобранное значение сохраняется раз в несколько минут, после перезагрузки клиент начинает с него;
   - в Setup и веб-интерфейсе: переключатель «Автоусиление», диапазон (по умолчанию 0–30 дБ), текущее значение.
5. **Мультирум (Snapcast)** — следующим этапом: синхронная музыка, голос Ирины поверх неё с приглушением музыки,
   затем эхоподавление ESP-SR, чтобы Ирина слышала команды во время музыки.
