# Ирина: голосовой помощник для умного дома

Офлайн-помощник на основе [Irene Voice Assistant](https://github.com/janvarev/Irene-Voice-Assistant) (Владислав Январёв).
Сервер — ТВ-приставка на Armbian (S905 с 1 ГБ, RK3528 с 2 ГБ) или компьютер с Windows/Linux. В комнатах — клиенты на ESP32
с микрофоном и усилителем: распознавание и синтез речи идут на сервере, ответ звучит в той комнате, откуда спросили.

Распознавание (Vosk через sherpa-onnx) и голос (vosk-tts) работают без интернета. Интернет нужен только Яндекс Музыке.

## Что внутри

| Часть | Файлы | Что делает |
|---|---|---|
| Сервер комнат | `runva_rooms.py` | Клиенты ESP32 по WebSocket, распознавание, выбор комнаты, ответы в комнату |
| Веб-интерфейс | `web_ui.py`, `web/index.html` | Комнаты, команды, сценарии, настройки, журнал — `http://<IP сервера>:8765/` |
| Ядро | `vacore.py`, `jaa.py` | Плагины, команды, диалоги, таймеры, озвучка |
| Клиент комнаты | `esp32_client/` | Прошивка ESP32 / ESP32-S3 (Arduino IDE) |
| Установка | `scripts/rk3528/install.sh`, `install_windows.bat` | Приставка / Windows |

Плагины (`plugins/`, каждый — отдельный файл, лишний можно просто удалить):

| Плагин | Команды и назначение |
|---|---|
| `plugin_homeassistant` | «включи свет на кухне», «выключи весь свет», «яркость в спальне тридцать», «закрой шторы», «какая температура в детской», «какая погода», «погода на завтра», «сцена кино» |
| `plugin_yandex_music` | «включи музыку», «включи исполнителя …», «пауза», «дальше», «что играет», «лайк» |
| `plugin_scenes` | свои фразы и сценарии из нескольких команд |
| `plugin_timer` | «таймер на пять минут», «сколько осталось», «отмени таймер» |
| `plugin_datetime` | «который час», «какое сегодня число» |
| `plugin_rooms` | «объяви …» (во всех комнатах), «громкость голоса тридцать», «какая это комната» |
| `plugin_audio_sources` | «режим сопряжения» — Bluetooth-колонка (Linux) |
| `plugin_greetings`, `plugin_random`, `plugin_gamemoreless`, `plugin_voiceover` | «привет», «подбрось монетку», игра «больше-меньше», «скажи …» |
| `plugin_tts_vosk`, `plugin_tts_console` | голос vosk-tts; текст в консоль, если голос не загрузился |
| `plugin_playwav_aplay`, `plugin_playwav_sounddevice` | проигрывание на Linux / Windows |
| `plugin_normalizer_prepare` | числа, латиница и символы — в слова для озвучки |

Как написать свой плагин: [docs/PLUGINS.md](docs/PLUGINS.md).
Из форка [AlexeyBond](https://github.com/AlexeyBond/Irene-Voice-Assistant) взяты идеи диалогов на генераторах, сценариев,
очистки кэша озвучки, записи звука для отладки и произношение времени с падежами (`utils/ru_speech`).

## Установка

**Приставка (Armbian/Debian, aarch64):**
```bash
git clone -b rk3528 https://github.com/Wint-Tele100gramm/IreneWint.git ~/irene
cd ~/irene
PYTHON=/usr/local/bin/python3.13 bash scripts/rk3528/install.sh
```
Параметры: `--no-bt`, `--no-airplay`, `--no-dlna`, `--aec` (эхоподавление), `--lite` / `--full`.
Python должен быть собран с `ssl`, `ctypes`, `sqlite3` — скрипт это проверит.

**Windows 10/11:** [README_WINDOWS.md](README_WINDOWS.md).

Дальше всё настраивается в веб-интерфейсе `http://<IP сервера>:8765/` (пароль — ключ клиентов,
`token` в `runva_rooms.json`; установщик его покажет).

## Веб-интерфейс

- **Комнаты** — клиенты на связи, прошивка, Wi-Fi, обрывы, причина перезагрузки; назначение комнаты (зоны Home Assistant
  из списка), громкость голоса, уровни речи; у микрофона самого сервера — усиление и живой индикатор.
- **Команды** — команда текстом в любой комнате, последние услышанные фразы, список команд.
- **Сценарии** — редактор сценариев и своих фраз, работает сразу.
- **Настройки** — имена помощника, голос («Послушать»), Home Assistant, вход в Яндекс Музыку по коду
  (только с правами Музыки), время, таймер, сервер. Нужен перезапуск — появится кнопка.
- **Журнал** — события сервера, выбор устройств Home Assistant, записи фраз.

Страница для домашней сети: порт 8765 в интернет не открывайте. Выключить: `"web_ui": false` в `runva_rooms.json`.

## Home Assistant

Токен: HA → Профиль → Безопасность → Долгосрочные токены доступа. Адрес и токен — в «Настройках» веб-интерфейса.

- Устройства ищутся по имени и зоне HA. Если названа комната, поиск идёт только в этой зоне; реле света ZHA (домен
  `switch`) тоже считаются светом. Что именно выбрано — видно в «Журнале».
- Без комнаты в команде берётся комната клиента: «включи свет» в спальне включит свет в зоне «Спальня».
- Одинаковые устройства в разных комнатах — Ирина переспросит: «Люстру где: Кухня или Спальня?»
- Устройство без связи (Zigbee) — Ирина так и скажет, а не отчитается впустую.
- Погода — из интеграции погоды HA (Яндекс Погода, Met.no и др.).
- Неудобное имя — синоним в `options/plugin_homeassistant.json`:
  `"aliases": { "ночник": "light.0x00158d0001a2b3c4", "свет в зале": ["light.a", "light.b"] }`.

## Яндекс Музыка

Вход — кнопкой в «Настройках» (код вводится на ya.ru/device) или `.venv/bin/python scripts/rk3528/yandex_token.py`.
Запрашиваются только права Музыки. Нужна подписка Плюс. Пока Ирина слушает команду, музыка приглушается.

## Звук с телефона (приставка)

| Откуда | Как |
|---|---|
| iPhone / iPad | Пункт управления → AirPlay → «Ирина» |
| Android и iOS | «Ирина, режим сопряжения» → в Bluetooth телефона выбрать **Irene** (3 минуты) |
| Android | Приложение с DLNA/UPnP (BubbleUPnP, Hi-Fi Cast) → «Ирина» |

Встроенный Bluetooth приставок часто не поддерживается ядром Armbian — подойдёт USB-донгл (RTL8761B).

## Комнаты

- Клиент: [esp32_client/README.md](esp32_client/README.md). Название комнаты = зона в Home Assistant
  (можно назначить на странице «Комнаты», не трогая клиент).
- Одну фразу услышали несколько клиентов — ответит тот, где громче; команда выполнится один раз.
- Таймеры и их сигнал звучат в той комнате, где их поставили; если клиент отключился — во всех комнатах.
- Микрофон самого сервера тоже может быть комнатой: «Микрофон приставки как комната» в настройках.
- Распознавание работает, только пока в комнате говорят — 5–6 комнат не нагружают сервер постоянно.

### Сценарии

На странице «Сценарии» или в `options/plugin_scenes.json`:
```json
{
    "aliases": { "зажги|сделай светло": "включи свет" },
    "scenes": {
        "спокойной ночи": ["выключи весь свет", "выключи музыку", "скажи: Спокойной ночи!"],
        "доброе утро": ["включи свет на кухне", "время", "какая погода", "включи музыку"]
    },
    "quiet_steps": true
}
```
Шаг — любая команда, `скажи: текст` или `пауза: секунды`. Свои фразы важнее одноимённых встроенных команд.

### Диалоги в своих плагинах

Команда может вернуть генератор: `answer = yield "Вопрос?"` (или `yield ("Вопрос?", 15)` с таймаутом).
Ответ ждётся без имени и в той же комнате; без ответа в генератор придёт `DialogTimeout` (`from vacore import DialogTimeout`).

## Распознавание, голос, кэш

- Распознавание: малая потоковая модель Vosk int8 — ~100 МБ ОЗУ на все комнаты.
  `bash scripts/rk3528/get_asr_model.sh full` — полная 0.56 (~250 МБ ОЗУ, точнее; для 2 ГБ и больше).
- Голос: vosk-tts, `vosk-model-tts-ru-0.7-multi` в `~/.cache/vosk`, голоса 0–4 (2 — «Ирина»).
- Кэш ответов (`tts_cache/`) чистится раз в 6 часов: не больше 300 МБ и без фраз, не звучавших 90 дней.
- Запись фраз для отладки: «Записывать фразы в WAV» в настройках — слушать на вкладке «Журнал».

## Эхоподавление на приставке

```bash
bash scripts/rk3528/enable_aec.sh        # включить
bash scripts/rk3528/enable_aec.sh off    # выключить
```
PipeWire вычитает звук динамика из микрофона приставки: Ирину можно перебить («стоп», «хватит»), а «Ирина, …» слышно поверх
музыки. Перед включением выберите реальные микрофон и динамик по умолчанию (`pactl set-default-source/sink`).

## Приставка с 1 ГБ ОЗУ

`install.sh` сам включает облегчённый режим при ОЗУ меньше 1,5 ГБ: без DLNA и Bluetooth, zram-подкачка, лимит памяти
Ирины 800 МБ. Ориентировочно: распознавание ~100 МБ, голос ~250 МБ, mpv + PipeWire + shairport-sync ~100 МБ.

## Управление

```bash
systemctl --user restart irene          # перезапуск (или кнопкой в веб-интерфейсе)
journalctl --user-unit irene -f         # логи
.venv/bin/python scripts/rk3528/irene_cmd.py "ирина который час"   # команда текстом из консоли
```
