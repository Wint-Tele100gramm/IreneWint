# Ирина на ТВ-приставке RK3528

Сборка голосового помощника Ирина для приставки на RK3528 (4×Cortex-A53, 2 ГБ ОЗУ, 16 ГБ eMMC, Armbian, Python 3.13).

Что добавлено к оригинальному проекту:

| Компонент | Файл | Что делает |
|---|---|---|
| Home Assistant | `plugins/plugin_homeassistant.py` | Управляет устройствами HA (в т.ч. ZHA/Zigbee) по имени и зоне |
| Яндекс Музыка | `plugins/plugin_yandex_music.py` | Моя волна, поиск, исполнители, альбомы, плейлисты, лайки |
| Звук с телефона | `plugins/plugin_audio_sources.py` + `scripts/rk3528/` | AirPlay (iOS), Bluetooth (Android и iOS), DLNA (Android) |
| Зависимости | `requirements-rk3528.txt` | Без gradio, torch и fastapi |
| Установка | `scripts/rk3528/install.sh` | Пакеты, venv, PipeWire, сервисы systemd |
| Комнаты | `runva_rooms.py`, `plugins/plugin_rooms.py`, `esp32_client/` | Сервер для клиентов ESP32 в комнатах и их прошивка |
| Сценарии | `plugins/plugin_scenes.py` | Свои фразы для команд и сценарии из нескольких команд |

Из форка [AlexeyBond](https://github.com/AlexeyBond/Irene-Voice-Assistant) взяты идеи диалогов на генераторах, сценариев,
очистки кэша озвучки, записи звука для отладки и произношение времени с падежами (`utils/ru_speech`).

Отключены плагины только для Windows (`plugin_mediacmds`, `plugin_mpchcmult`) и `pyttsx`/`audioplayer` — они лежат в `plugins_inactive/`.

## Установка

```bash
git clone -b rk3528 https://github.com/Wint-Tele100gramm/IreneWint.git ~/irene
cd ~/irene
PYTHON=/usr/local/bin/python3.13 bash scripts/rk3528/install.sh
```

Параметры: `--no-bt`, `--no-airplay`, `--no-dlna`, `--aec` (эхоподавление, чтобы Ирина лучше слышала имя поверх музыки).

Ваш Python 3.13 должен быть собран с модулями `ssl`, `ctypes`, `sqlite3` (пакеты `libssl-dev libffi-dev libsqlite3-dev` до сборки) — скрипт это проверит.

### Home Assistant

1. В HA: Профиль → Безопасность → Долгосрочные токены доступа → Создать.
2. Впишите адрес и токен в `options/plugin_homeassistant.json`:
   ```json
   { "v": "1.0", "url": "http://192.168.1.10:8123", "token": "eyJ...", "aliases": {} }
   ```
3. Устройства ищутся по их имени и зоне в HA. Если имя неудобно произносить, добавьте синоним:
   `"aliases": { "ночник": "light.0x00158d0001a2b3c4", "свет в зале": ["light.a", "light.b"] }`

Команды: «ирина включи свет на кухне», «выключи весь свет», «яркость в спальне тридцать», «закрой шторы», «включи розетку телевизора», «какая температура в детской», «сцена кино», «обнови устройства».

### Яндекс Музыка

```bash
.venv/bin/python scripts/rk3528/yandex_token.py
```
Скрипт покажет код — введите его на ya.ru/device с телефона. Нужна подписка Плюс.

Команды: «включи музыку» (Моя волна), «поставь кино группа крови», «включи исполнителя сплин», «включи альбом ...», «включи плейлист ...», «включи любимые песни», «пауза», «продолжи», «дальше», «назад», «громче», «тише», «громкость сорок», «что играет», «лайк», «не нравится», «выключи музыку».

Когда вы говорите «Ирина», музыка приглушается, пока команда не выполнится.

### Звук с телефона

| Откуда | Как |
|---|---|
| iPhone / iPad | Пункт управления → AirPlay → «Ирина» |
| Android и iOS | «Ирина, режим сопряжения» → в Bluetooth телефона выбрать **Irene** (3 минуты на подключение) |
| Android | Приложение с DLNA/UPnP (BubbleUPnP, Hi-Fi Cast и др.) → устройство «Ирина» |

Когда начинается AirPlay, Яндекс Музыка на приставке ставится на паузу.

Bluetooth: встроенный модуль приставок на RK3528 часто не поддерживается ядром Armbian. Если `bluetoothctl list` пуст — возьмите USB-донгл (например, на чипе RTL8761B).

## Комнаты: клиенты на ESP32

Приставка работает как сервер комнат (`runva_rooms.py`): в каждой комнате стоит ESP32 с микрофоном и
усилителем, звук приходит по Wi-Fi, распознавание и синтез идут на приставке, ответ звучит в той комнате,
откуда пришла команда. Сборка и настройка клиента — [esp32_client/README.md](esp32_client/README.md).

- Ключ для клиентов создаётся при установке и лежит в `runva_rooms.json` (`token`).
- Название комнаты в клиенте = зона в Home Assistant. Тогда «Ирина, включи свет» включит свет в этой комнате,
  а «какая температура» — покажет датчик этой комнаты. «Включи свет на кухне» работает из любой комнаты.
- Микрофон самой приставки тоже может быть комнатой: `"local_room": "Гостиная"` в `runva_rooms.json`.
- Команды: «объяви ужин готов» (во всех комнатах), «громкость голоса тридцать», «голос тише»,
  «какая это комната», «какие комнаты подключены».
- Музыка (Яндекс Музыка, AirPlay, Bluetooth) по-прежнему играет на приставке.

Нагрузка: распознавание работает только пока в комнате говорят (детектор речи на ESP32), поэтому
даже 5–6 комнат не загружают приставку постоянно. С новой моделью все комнаты делят одну модель в памяти.

### Таймеры и события в комнатах

«Ирина, таймер на пять минут» / «поставь таймер на час двадцать минут» / «засеки полчаса»,
«сколько осталось», «отмени таймер». Сигнал и фраза звучат в той комнате, где таймер поставили.
Если клиент этой комнаты к тому времени отключился — во всех подключённых комнатах.

### Свои фразы и сценарии

`options/plugin_scenes.json` (создаётся при первом запуске), без программирования:

```json
{
    "aliases": {
        "зажги|сделай светло": "включи свет",
        "я пришёл": "включи свет в прихожей"
    },
    "scenes": {
        "спокойной ночи": ["выключи весь свет", "выключи музыку", "скажи: Спокойной ночи!"],
        "доброе утро": ["включи свет на кухне", "время", "включи музыку"],
        "кино": ["выключи весь свет", "пауза: 1", "включи торшер в гостиной", "скажи: Приятного просмотра"]
    },
    "quiet_steps": true
}
```
- псевдоним передаёт остаток фразы дальше: «ирина зажги на кухне» = «ирина включи свет на кухне»;
- шаг сценария — любая команда (как после имени), `скажи: текст` или `пауза: секунды`;
- `quiet_steps: true` — подтверждения шагов («Выключаю…») не произносятся, звучат только `скажи:`.

После правки: `systemctl --user restart irene`.

### Уточняющие вопросы

Если одинаковые устройства есть в нескольких комнатах, а команда пришла без комнаты
(«Ирина, включи люстру» с приставки или из комнаты без люстры), Ирина спросит:
«Люстру где: Кухня или Спальня?» — отвечайте без имени: «на кухне», «везде». «Ирина, включи» — «Что включить?».

Для своих плагинов: команда может вернуть генератор — `answer = yield "Вопрос?"` (или `yield ("Вопрос?", 15)`
с таймаутом), без ответа в генератор придёт `DialogTimeout` (`from vacore import DialogTimeout`).

### Время

«Который час» — «Сейчас без четверти восемь вечера». Формат — `options/plugin_datetime.json`:
`"style": "digital"` — «девятнадцать сорок пять», `"sayDayPart": false` — без «утра/вечера».

### Отладка распознавания: запись звука из комнат

Если Ирина плохо понимает какую-то комнату, послушайте, что на самом деле приходит с микрофона:
`"dump_audio": "/tmp/irene-dump"` в `runva_rooms.json` и перезапуск. Каждая фраза сохраняется как
`время_комната_уровень_распознанное.wav` (хранятся последние `dump_keep` = 300). Не забудьте выключить (`""`).

### Кэш озвучки

Ответы кэшируются (`tts_cache/`) и звучат сразу. Раз в 6 часов кэш чистится: не больше `tts_cache_max_mb`
(300 МБ) и без фраз, не звучавших `tts_cache_max_days` (90) дней — настройки в `runva_rooms.json`.
После смены голоса в настройках TTS старые фразы не звучат прежним голосом.

## Эхоподавление и «перебивание» Ирины (микрофон приставки)

```bash
bash scripts/rk3528/enable_aec.sh        # включить
bash scripts/rk3528/enable_aec.sh off    # выключить
```
PipeWire вычитает из записи микрофона то, что играет динамик (WebRTC AEC). Микрофон приставки больше
не отключается во время ответа: «стоп», «хватит», «замолчи» прерывают ответ, «Ирина, …» — прерывает и
выполняет новую команду. Во время музыки работает «Ирина, стоп» / «Ирина, пауза». Нагрузка — ~10–20% одного ядра.
Перед включением выберите реальные микрофон и динамик устройствами по умолчанию (`pactl set-default-source/sink`).

Клиенты ESP32 по-прежнему не слушают, пока говорят: на классическом ESP32 эхоподавление не потянуть.

## Распознавание речи

По умолчанию — новая потоковая модель Vosk (Zipformer) через sherpa-onnx, малая int8-версия:
около 100 МБ ОЗУ и ~11% ошибок (у старой vosk-model-small-ru-0.22 — ~30% и ~250 МБ).
Одна модель обслуживает все комнаты, каждая новая комната почти не добавляет памяти.

```bash
bash scripts/rk3528/get_asr_model.sh         # малая модель (ставится при установке)
bash scripts/rk3528/get_asr_model.sh full    # полная 0.56 (~250 МБ ОЗУ, точнее) — только для 2 ГБ и больше
```
Вернуться на старый Vosk: `"asr": "kaldi"` в `runva_rooms.json`. Если новой модели нет, Ирина сама переключится на старую.

## Приставка с 1 ГБ ОЗУ (например, S905)

`install.sh` сам включает облегчённый режим, если ОЗУ меньше 1,5 ГБ (или вручную: `--lite`):
без DLNA и Bluetooth, со сжатой подкачкой zram и лимитом памяти Ирины 800 МБ. Silero на такой
приставке недоступен — только vosk-tts. AirPlay и Яндекс Музыка работают.

## Голос: vosk-tts или Silero v4

По умолчанию — vosk-tts (быстрый и лёгкий). Silero v4 звучит естественнее и сам ставит ударения,
но требует PyTorch (~400 МБ на диске, +200–300 МБ ОЗУ) и синтезирует медленнее (на A53 — порядка 1–3 с на фразу).
Повторяющиеся ответы кэшируются и звучат сразу.

```bash
bash scripts/rk3528/switch_tts.sh silero   # включить Silero v4
bash scripts/rk3528/switch_tts.sh vosk     # вернуть vosk-tts
```

Голос Silero: `options/plugin_tts_silero_v4.json` → `"speaker"`: `xenia`, `kseniya`, `baya` (женские), `aidar`, `eugene` (мужские).

## Управление сервисом

```bash
systemctl --user start irene irene-airplay irene-dlna
systemctl --user restart irene
journalctl --user-unit irene -f
```

## Память (ориентировочно)

| Процесс | ОЗУ |
|---|---|
| Vosk small-ru (распознавание) | ~300 МБ |
| vosk-tts (озвучка) | ~250–400 МБ |
| mpv + PipeWire + shairport-sync + gmediarender | ~100 МБ |

Сервис Ирины ограничен 1,2 ГБ (`MemoryMax` в `irene.service`). Home Assistant лучше держать на отдельной машине.

## Микрофон

Нужен USB-микрофон или USB-звуковая карта с микрофоном. Проверка: `arecord -l`, `pactl list short sources`. Ирина слушает источник по умолчанию PipeWire (`pactl set-default-source ...`).
